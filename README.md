# בוט־ניק 🌱

בוט טלגרם אישי לניהול הגינה במרפסת.

## התקנה (פעם אחת)

```bash
uv venv --python 3.12 .venv     # או: python3.12 -m venv .venv
source .venv/bin/activate        # ב-Windows: .venv\Scripts\activate
uv pip install -r requirements.txt   # או: pip install -r requirements.txt
cp .env.example .env             # ואז למלא את הטוקן מ-@BotFather
```

## הרצה

```bash
python -m botnik.seed    # טעינה ראשונה בלבד של data/garden.yaml למסד הנתונים
python -m botnik.bot     # מפעיל את הבוט
```

שולחים לבוט `/myid`, מעתיקים את המספר ל-`ALLOWED_USER_IDS` בקובץ `.env`, ומפעילים מחדש.

## בדיקות

```bash
pytest
```

## פקודות בטלגרם

- `/start` – מה הבוט יודע לעשות
- `/garden` – כל הגינה לפי אזורים; לחיצה על אזור ואז על עציץ פותחת את הכרטיס המלא
- `/missing` – עציצים שחסרים להם פרטים
- `/sun` – שעות שמש לפי אזור (לעונה הנוכחית)
- `/cancel` – הפסקת שאלות פתוחות
- `/today` – מה לעשות היום (מגיע לבד כל בוקר ב־05:50)
- `/water`, `/feed` – רישום השקיה ודישון לכל הגינה, לאזור או לעציץ
- `/care` – כמה מים ואיזה דישון כל צמח צריך (לבדיקה ותיקון)
- `/settings` – שעות תדריך הבוקר וסיכום הערב (19:30)
- `/doctor` – בעיה בצמח: מזיקים ומחלות, תוכנית טיפול ומעקב
- 📷 תמונה עם הכיתוב `#21` – נשמרת לעציץ 21 (בלי נתוני מיקום)

בכרטיס של כל עציץ: `💧 השקיתי`, `🌱 דישנתי`, `✏️ השלמת פרטים` (כשחסר משהו), `🔄 שינוי מצב`, `📍 הזזה`.
התזכורות מגיעות רק כשהבוט רץ – עד המעבר לשרת, המחשב צריך להיות דלוק והבוט פועל.
כל תשובה נשמרת מיד.
- `/myid` – מספר המשתמש שלך (עובד גם לפני שנוספת לרשימה המורשית)

שינוי בקוד דורש הפעלה מחדש של הבוט (Ctrl+C ואז שוב `python -m botnik.bot`).
אחרי הטעינה הראשונה, מסד הנתונים הוא מקור האמת והשינויים נעשים בבוט.
הרצה חוזרת של `python -m botnik.seed` מסרבת לדרוס אותו.
`python -m botnik.seed --reset` מוחק את כל השינויים מהבוט וטוען מחדש את `garden.yaml` (מבקש לכתוב yes).

## גיבוי מסד הנתונים

`botnik.db` לא נשמר ב־git ולא ב־GitHub, וכל מה שממלאים בבוט נמצא רק בו. גיבוי פשוט:

```bash
mkdir -p backups && cp botnik.db backups/botnik-$(date +%F).db
```

## השרת (Railway)

הבוט רץ ב־Railway ומתעדכן לבד בכל `git push` ל־GitHub.
- משתנים ב־Railway (לא ב־git): `TELEGRAM_BOT_TOKEN`, `ALLOWED_USER_IDS`, `BOTNIK_DB_PATH=/data/botnik.db`
- Volume מחובר ב־`/data` – שם נשמר מסד הנתונים, וגיבוי לילי ב־`/data/backups` (14 ימים).
- `/backup` בטלגרם שולח לך קובץ גיבוי. `/restore` ואז שליחת הקובץ – משחזר.
- **לא להפעיל את הבוט במחשב כשהוא רץ בשרת** – שני עותקים גונבים זה לזה הודעות.
